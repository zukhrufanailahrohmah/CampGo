# CampGo

Aplikasi persewaan alat camping (UAS Pemrograman Web 2026/2027). PHP Native + MySQL.

## Menjalankan
1. Letakkan folder di `htdocs` XAMPP (PHP 8.0+), nyalakan Apache dan MySQL.
2. Import `database/campgo_db.sql` di phpMyAdmin.
3. Buka `http://localhost/<nama-folder>/database/seed_demo.php` sekali untuk akun demo dan data contoh.
4. Buka `http://localhost/<nama-folder>/`.

Akun demo: `admin@demo.test` / `Admin#2026`, `staff@demo.test` / `Staff#2026`, `user@demo.test` / `User#2026`.

Dokumentasi: `docs/` (Master Document, `BACKEND_IRUL.md` untuk kontrak handler dan aturan booking).
